  测速前台: http://127.0.0.1:8080
  管理后台: http://127.0.0.1:8080/admin

2. Service:
  {{ include "dn11dog.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.httpPort }}  (http: Web / API / SSE / 安装脚本 / Agent 反连 WebSocket /api/v1/agent/ws)
